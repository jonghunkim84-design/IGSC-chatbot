# IGSC 인증 문의 챗봇 시스템 매뉴얼

국제지속가능인증원(IGSC)의 고객 문의 응대 챗봇과 관리자 화면을 **이해하고, 운영하는 데** 필요한 내용을 한 문서에 모았습니다.
(2026-09-30 기준, 문서 기반 FAQ 초안·검수·재검토 기능 포함)

## 0. 이 문서 보는 법

| 읽는 분 | 먼저 볼 곳 |
|---|---|
| 시스템이 어떻게 동작하는지 이해하고 싶은 분 | 1장 → 2장 |
| **챗봇을 이용하는 고객** (고객사에 안내문으로 제공 가능) | 3장 |
| **관리자(운영 담당자)** | 4장 → 5장 → 6장 |
| **문서에서 FAQ 초안을 만들려는 운영자** | 4-9 ~ 4-12 |
| 시스템 관리·배포 담당 (외주 포함) | 8장, 9장 |
| 막혔을 때 | 7장 (문제 해결) |

## 1. 시스템 한눈에

### 무엇인가
고객이 웹사이트의 챗봇에 인증 관련 질문(가능 여부, 비용, 기간, 절차, 서류)을 하면, **승인된 FAQ에 있는 내용만** 근거로 답하는 안내 챗봇입니다. 자료에 없거나 답하면 안 되는 질문은 **답하지 않고 담당자에게 연결**합니다.

### 구성

| 구성 요소 | 하는 일 | 사용하는 사람 |
|---|---|---|
| **챗봇 화면** (웹사이트 우측 하단 버튼) | 고객 질문을 받아 답변 | 고객 |
| **관리자 화면** (`/admin`) | FAQ 등록·승인, 미답변 질문 처리, 대화 로그·통계 확인 | 운영 담당자 |
| **데이터 저장소** (Supabase) | FAQ, 대화 기록, 미답변 질문, 인증 이력 | (시스템) |

### 지켜지는 원칙 (시스템이 강제합니다)

1. **승인된 FAQ만 근거로 답합니다.** 해당 FAQ가 없으면 답을 만들어내지 않고 담당자로 연결합니다.
2. **컨설팅은 거절합니다.** "어떻게 하면 통과하나요" 같은 질문에는 어떤 경우에도 방법을 안내하지 않습니다. 인증기관은 심사 대상에게 컨설팅을 제공할 수 없습니다(ISO 17065 공평성).
3. **비용·기간은 등록된 확정값만** 안내하고, 항상 "참고용이며 담당자 검토 후 확정" 문구를 붙입니다.
4. **제품의 인증 가능 여부는 확답하지 않습니다.** 유사한 인증 이력만 참고로 안내합니다.
5. **모든 대화가 기록되고**, 답하지 못한 질문은 관리자에게 모입니다.

### 운영의 핵심: 선순환

```
 고객이 질문 ──▶ 챗봇이 답변 (승인 FAQ가 있으면)
      │
      └─ 답하지 못함 ──▶ [미답변 질문]에 쌓임 ──▶ 관리자가 FAQ로 등록·승인 ──▶ 다음 고객부터 즉시 답변
```

> **챗봇의 실력 = 승인된 FAQ의 양과 질** 입니다. 운영은 이 순환을 꾸준히 돌리는 일입니다.

## 2. 챗봇은 질문을 어떻게 처리하나

모든 질문은 아래 순서를 **반드시** 거칩니다.

1. **분류**: 질문을 4가지로 나눕니다 — 인증 정보 문의 / 컨설팅 요청 / 불만·이의제기 / 인증과 무관한 질문
2. **분기**: 컨설팅·불만·무관한 질문은 **여기서 끝**나고 정해진 안내 문구만 나갑니다. (AI가 답을 만들지 않습니다.)
3. **FAQ 선택**: 인증 정보 문의는 승인된 FAQ 중 관련된 것을 최대 3개 고릅니다. 없으면 담당자에게 연결합니다.
4. **답변 작성**: 고른 FAQ의 내용만으로 답합니다. 출처 링크와 필요한 안내 문구는 시스템이 자동으로 붙입니다.
5. **기록**: 질문·답변·근거 FAQ를 대화 로그에 남깁니다. 답하지 못한 질문은 미답변 목록에도 올라갑니다.

### 처리 결과(route)와 운영자가 할 일

관리자 화면의 대시보드·대화 로그에는 아래 처리 결과가 표시됩니다.

| 처리 결과 | 언제 | 고객에게 나가는 것 | 운영자가 할 일 |
|---|---|---|---|
| **답변 완료** | 승인 FAQ로 답함 | 답변 + 출처 링크 (+ 필요 시 안내 문구) | 대화 로그에서 가끔 정확성 확인 |
| **담당자 이관** | 근거 FAQ가 없음 / 'FAQ 보완 필요' 항목 / 시스템 오류 / 영어 등 미지원 언어 | "담당자 확인이 필요합니다" + 연락처 | **미답변 질문**에서 FAQ로 등록 (가장 중요) |
| **인증 종류 되묻기** | 어떤 인증인지 알 수 없는 질문 (예: "얼마나 걸려요?") | "어떤 인증인가요?" + 인증 선택 버튼 | 없음 (고객이 버튼을 누르면 이어짐) |
| **컨설팅 차단** | 통과 방법·기준 맞추는 법 등 요청 | 공평성 안내 + 외부 컨설팅 안내 | 없음. 이 요청에 답하는 FAQ를 만들지 않기 |
| **불만 접수** | 불만·이의제기·항의 | 접수 방법 + 연락처 | **담당자가 직접 대응** (대화 로그에서 내용 확인) |
| **범위 밖** | 인증과 무관한 질문 | "인증 문의 전용" 안내 | 없음 |

### 시스템이 자동으로 붙이는 것 (FAQ에 직접 적지 않아도 됩니다)

| 자동 첨부 | 조건 |
|---|---|
| **출처 링크** | 답변 근거 FAQ에 출처 URL이 있을 때 |
| **"비용·기간은 참고용이며 담당자 검토 후 확정됩니다"** | 카테고리가 비용·기간인 FAQ로 답할 때 |
| **"인증 가능 여부는 담당자가 검토한 뒤 확정됩니다"** | 제품의 인증 가능 여부를 묻는 질문일 때 |
| **유사 인증 이력** | 가능 여부 문의이고, 공개 동의된 이력이 있을 때 (7장) |

### '보완 필요' 항목이란
답변이 아직 확정되지 않아 **비워 둔 FAQ**입니다(예: 인증별 비용·기간). 챗봇은 이 항목을 근거로 답하지 않고 담당자 안내로 처리합니다. 답변을 채우고 표시를 해제해 승인하면 그때부터 답합니다.

## 3. 고객용: 챗봇 사용 방법

> 이 장은 고객사에 안내문으로 그대로 제공할 수 있습니다.

### 3-1. 시작하기
1. 화면 **우측 하단의 동그란 버튼**을 누릅니다. (PC: 작은 대화창 / 스마트폰: 화면 전체 — 닫을 때는 오른쪽 위 **✕**)
2. **추천 질문 버튼**을 누르거나, 입력창에 질문을 적고 **전송**을 누릅니다.

| 추천 질문 | 알 수 있는 것 |
|---|---|
| 인증 비용 | 인증 종류별 비용 안내 |
| 소요 기간 | 인증까지 걸리는 기간 |
| 인증 절차 | 신청부터 발급까지의 절차 |
| 인증 종류 안내 | 안내 가능한 인증 목록 |

대화창을 닫았다 다시 열면 대화가 남아 있고, 페이지를 새로고침하면 처음부터 다시 시작합니다.

### 3-2. 이렇게 물어보세요
**인증 종류를 함께 적으면 가장 정확합니다.**

| 좋은 질문 | 아쉬운 질문 |
|---|---|
| 비건 인증 비용이 얼마인가요? | 얼마예요? |
| 유기농 인증은 어떤 인증인가요? | 그거 뭐예요? |
| 식품 비건 인증은 어떤 원칙으로 심사하나요? | 심사는 어떻게 해요? |

- 한 번에 **하나의 질문**을 하면 더 정확합니다. 500자 이내, **한국어**로 적어 주세요.
- 인증 종류가 없으면 챗봇이 **"어떤 인증에 대한 문의이신가요?"** 하고 되묻습니다. 아래 **인증 종류 버튼**을 누르면 이어서 답합니다.

### 3-3. 답변 보는 법
- **'출처 ↗'**: 답변의 근거가 된 공식 페이지입니다.
- **'상담 신청 ↗'**: IGSC 상담(Q&A) 페이지가 새 창으로 열립니다. 담당자와 직접 이야기하고 싶을 때 이용하세요.
- **비용·기간 답변**에는 **"참고용이며 담당자 검토 후 확정됩니다"** 문구가 항상 함께 표시됩니다.

### 3-4. 챗봇이 도와드리는 것 / 드릴 수 없는 것

**도와드리는 것**: 인증이 무엇인지, 심사 원칙·기준, 대상·범위, 절차, 필요 서류, 비용, 기간, 갱신. 제품의 인증 가능 여부 문의는 **단정하지 않고**, 유사한 제품군의 인증 이력을 참고로 안내하며 최종 판단은 담당자가 제품 정보를 검토해 확정합니다.

| 상황 | 챗봇의 응답 | 이유 |
|---|---|---|
| "어떻게 하면 통과하나요?" 등 **컨설팅 요청** | 답하지 않고 안내 문구 | IGSC는 인증기관(ISO 17065)으로서 **공평성 보장을 위해 컨설팅을 제공하지 않습니다.** 준비·개선은 외부 전문 컨설팅 기관에 문의하세요. |
| **불만·이의제기** | 자동 답변 없이 담당자 연결 방법 안내 | 담당자가 직접 처리합니다. |
| 인증과 무관한 질문 | 인증 문의 전용이라고 안내 | |
| 안내 자료에 없는 내용 | "담당자 확인이 필요합니다" | 확인되지 않은 내용을 추측하지 않습니다. |

### 3-5. 자주 묻는 상황
- **"담당자 확인이 필요합니다"라고 나와요** → 공식 자료에서 확인할 수 없는 내용입니다. 문의 내용이 담당자 확인 대상으로 기록됩니다. 빠른 확인이 필요하면 연락처로 문의하세요.
- **비용·기간을 물었는데 금액이 안 나와요** → 확정된 안내 값이 아직 등록되지 않은 항목은 임의로 안내하지 않고 담당자 확인으로 연결합니다. **상담 신청**을 이용해 주세요.
- **불만·이의를 제기하고 싶어요** → 전화·방문·홈페이지로 접수할 수 있습니다. 홈페이지에서는 **이의제기/불만 접수 신청 양식**을 작성해 **Q&A – 고객 불만**에 첨부해 주세요.

### 3-6. 개인정보
챗봇에는 **연락처, 주민등록번호, 사업자 정보 등 개인정보를 입력하지 마세요.** 입력하신 질문과 답변은 서비스 품질 관리와 안내 자료 개선을 위해 기록됩니다.

## 4. 운영자용: 관리자 화면

### 4-1. 로그인
1. `/admin` 접속 → 등록된 이메일 입력 → **로그인 링크 받기**
2. 메일의 링크를 **요청한 같은 브라우저**에서 클릭
3. 등록되지 않은 이메일은 메일이 발송되지 않습니다(화면에는 똑같은 안내가 나옵니다). 관리자 추가는 9장 참고.

### 4-2. 화면 구성

| 메뉴 | 용도 |
|---|---|
| **대시보드** | 오늘/이번 주 문의 수, 답변 성공률, 많이 묻는 질문 Top 10, 미처리 미답변 건수 |
| **FAQ** | FAQ 목록·검색·필터, 등록·수정, 일괄 승인 |
| **미답변 질문** | 챗봇이 답하지 못한 질문 → FAQ로 등록 / 처리 완료 |
| **대화 로그** | 날짜·처리 결과별 대화 조회, 근거로 쓴 FAQ 확인 |
| **문서 보관함** | 인증 관련 문서 업로드·개정·삭제, 텍스트 추출 상태 확인 (FAQ 초안의 재료) |

> **반영 시점**: 저장하면 챗봇 답변에 **바로** 반영됩니다(재배포·대기 없음). 단, **상태가 '승인'인 FAQ만** 챗봇이 사용합니다. '초안'은 고객에게 나가지 않습니다.

### 4-3. 핵심 동선 ① FAQ 새로 등록
1. **FAQ** 메뉴 → 오른쪽 위 **+ FAQ 등록**
2. 입력
   - **질문**: 고객이 물을 법한 문장 (예: `비건 인증 비용은 얼마인가요?`)
   - **다른 표현**: 같은 질문의 다른 말투를 한 줄에 하나씩 (예: `비건인증 얼마`, `비건 인증 가격`)
   - **답변**: 확정된 내용만 (6장 참고)
   - **인증 종류**, **카테고리**(절차/비용/기간/서류/대상·범위/갱신)
   - **출처 URL**: 답변 아래 '출처' 링크로 고객에게 보입니다
3. **상태 `승인`**으로 저장 → 챗봇이 바로 사용. 더 다듬을 게 있으면 `초안`으로 저장해 두었다가 나중에 승인하세요.

### 4-4. 핵심 동선 ② FAQ 수정
1. **FAQ** 목록에서 필터(인증 종류·카테고리·상태)나 **키워드 검색**으로 찾기
2. 질문을 클릭 → 수정 → **저장**
3. 챗봇에서 내리고 싶으면 **상태를 `초안`으로 바꿔 저장**합니다. (삭제하지 않아도 됩니다)
4. **초안 삭제**: 초안 상태인 FAQ는 수정 화면 아래쪽의 **삭제** 버튼으로 지울 수 있습니다(확인 창이 한 번 뜹니다). **승인된 FAQ는 삭제할 수 없습니다.** 출처 문서가 있는 초안은 문서 보관함의 **검수하기** 화면에서도 삭제할 수 있습니다.

### 4-5. 핵심 동선 ③ 미답변 질문 → FAQ로 등록
1. **미답변 질문** 메뉴 (대시보드의 '미처리 미답변 질문'을 눌러도 됩니다)
   - 챗봇이 "어떤 인증인가요?"라고 되물어 고객이 인증을 고른 경우, 질문은 **"인증 절차가 어떻게 되나요? / 환경성적표지(EPD)"** 처럼 처음 질문과 고른 인증을 `/` 로 합쳐 기록됩니다. 대화 로그에도 같은 형태로 남습니다.
2. 질문 오른쪽의 **직접 등록** 클릭 → 질문이 채워진 등록 화면이 열립니다. (문서에서 초안을 만들려면 4-10 참고)
3. **답변·인증 종류·카테고리**를 채우고 **저장**
   - 저장하면 그 미답변 질문은 **자동으로 '처리 완료'** 됩니다.
   - FAQ로 만들 필요가 없는 질문(잡담 등)은 **처리 완료** 버튼만 누르세요. 잘못 눌렀다면 '처리 완료' 탭에서 **미처리로 되돌리기**.

### 4-6. 승인 규칙
- 승인하려면 **답변이 있어야** 하고 **'담당자 입력 필요' 체크가 꺼져** 있어야 합니다. 조건이 안 맞으면 저장할 때 이유가 표시됩니다.
- **일괄 승인**: FAQ 목록에서 체크박스로 여러 개 선택 → **선택 항목 승인**. 답변이 비었거나 '보완 필요' 표시가 있는 항목은 선택할 수 없습니다.
- **'보완 필요' 항목 채우기**: 항목을 열면 상단에 노란 안내가 보입니다. 답변 입력 → '담당자 입력 필요' 체크 해제 → 상태 `승인` → 저장.

### 4-7. 대시보드 읽는 법
- **문의 수**: 챗봇에 입력된 질문 1건(버튼 선택 포함)마다 1로 셉니다. 기준은 한국 시간, 이번 주는 월요일부터입니다.
- **답변 성공률** = 답변 완료 ÷ (답변 완료 + 담당자 이관). 컨설팅 차단·불만·범위 밖·되묻기는 계산에 넣지 않습니다 — "챗봇이 답했어야 하는 질문 중 실제로 답한 비율"입니다.
- **Top 10**: 최근 30일간 같은 문장이 가장 많이 들어온 질문. **'담당자 이관'이 주된 처리인 질문은 FAQ 등록 1순위**입니다.
- **미처리 미답변 질문**: 0에 가깝게 유지하는 것이 목표입니다.
- **재검토 필요**: 출처 문서가 개정·삭제된 승인 FAQ의 수입니다(있을 때만 표시). 눌러서 처리하세요 (4-12).

### 4-8. 대화 로그 활용
날짜·처리 결과로 걸러 보고, 대화를 펼치면 **챗봇의 실제 응답**과 **근거로 쓴 FAQ**가 나옵니다. FAQ 이름을 누르면 바로 수정 화면으로 이동합니다.
- 고객이 이상하다고 한 답변 → 근거 FAQ를 열어 내용 확인·수정
- '불만 접수'로 분류된 대화 → **담당자가 직접 확인해 대응**

### 4-9. 문서 기반 FAQ 초안: 전체 흐름과 원칙

인증 절차서·안내문 같은 문서를 올려 두면, 미답변 질문에 대한 **FAQ 초안**을 문서에서 근거를 찾아 만들어 줍니다. 사람이 검수·승인한 것만 챗봇이 씁니다.

```
문서 업로드 → 텍스트 추출 → (미답변 질문에서) 초안 만들기 → 검수 → 승인 → 챗봇이 답변
```

**시스템이 지키는 원칙**
- **문서는 고객 답변의 근거가 아닙니다.** 챗봇은 문서를 직접 읽지 않고, **승인된 FAQ만** 근거로 답합니다.
- 만들어진 초안은 **항상 '초안' 상태**입니다. 승인은 **사람이 버튼을 눌러야만** 됩니다. 초안은 승인 전까지 챗봇에 나가지 않습니다.
- 문서에 **근거 문장이 없으면 답변을 지어내지 않고**, 빈 답변의 '보완 필요' 초안으로 남깁니다.
- 답변에 쓰인 숫자(비용·기간)와 근거 문장은 **문서 원문과 글자 그대로 대조**합니다. 원문에 없는 값이 들어간 초안은 자동으로 버려집니다.
- **컨설팅성 질문**("어떻게 하면 통과하나요")은 초안을 만들지 않습니다. 인증기관은 심사 대상에게 컨설팅을 제공할 수 없습니다(ISO 17065 공평성).

### 4-10. 문서 올리기와 초안 만들기
**① 문서 올리기** — **문서 보관함** 메뉴
1. 파일 선택(한 번에 최대 20개, 파일당 20MB) → **인증 종류·분류**를 정해 업로드
2. **분류**: 절차 / 비용·수수료 / 양식 / 규정·정책 중 알맞은 것을 고르세요. **'기타 (초안 제외)'로 분류한 문서는 FAQ 초안의 재료로 쓰이지 않습니다.** 챗봇 매뉴얼 같은 내부 문서나 인증 근거가 아닌 자료는 '기타'로 올리거나 올리지 마세요(인증 근거 문서와 섞이면 엉뚱한 초안이 만들어질 수 있습니다).
3. 형식: PDF, DOCX, XLSX, PPTX, CSV, TXT, MD. **HWP/HWPX는 올릴 수 없습니다** — 한글에서 PDF로 저장해 올려 주세요.
4. 업로드 후 자동으로 텍스트를 뽑습니다. 상태가 **추출 완료**가 되면 초안 재료로 쓸 수 있습니다.
5. **추출 실패**로 나오면 사유가 표시됩니다. 대표적으로 **스캔한 이미지 PDF**는 글자가 없어 실패합니다 — 텍스트가 있는 원본으로 다시 올려 주세요. 실패해도 올린 파일은 그대로 보관되고, **재추출** 버튼으로 다시 시도할 수 있습니다.
6. 문서 파일은 관리자만 내려받을 수 있습니다(외부 공개 없음).

**② 초안 만들기** — **미답변 질문** 메뉴
- 질문 한 건: 행의 **초안 만들기** 클릭
- 여러 건: 체크박스로 선택 → **선택 항목 초안 만들기** (한 번에 최대 10건, 자동 실행·야간 배치는 없습니다). 문서를 읽는 데 시간이 걸리며, 끝나면 목록에 **초안 있음**으로 바뀝니다.
- '문서에서 찾을 인증 종류'를 고르면 그 인증의 문서를 우선해서 찾습니다.
- 결과
  | 결과 | 화면 표시 |
  |---|---|
  | 근거를 찾아 초안 생성 | **초안 있음** + **검수하기** 버튼 |
  | 문서에 근거가 없음 / 검증에서 탈락 | 빈 답변의 **보완 필요** 초안 + **사유** 표시 |
  | 컨설팅성 질문 | 초안을 만들지 않고 안내 메시지 표시 |
  | 추출이 끝난 문서가 없음 | 문서를 올린 뒤 다시 시도하라는 안내 |

### 4-11. 초안 검수하고 승인하기
미답변 질문의 **검수하기**(또는 FAQ 목록에서 질문 클릭)로 검수 화면을 엽니다.

- **왼쪽**: 질문·답변·인증 종류 등 수정 폼 / **오른쪽**: **출처 카드** — 파일명, 페이지, 버전, 파일 내려받기
- **원문 보기**: 답변의 근거가 된 **원문 문장이 노란색으로 표시**된 문서 본문이 답변 옆에 나란히 보입니다. 답변이 원문과 같은 뜻인지 눈으로 대조하세요.
- **승인 방법 (2클릭 이내)**
  - 그대로 좋다 → 화면 위쪽 **승인** 버튼 한 번
  - 고쳐야 한다 → 답변을 수정한 뒤 **수정 후 승인**
  - 아직 아니다 → **저장**(초안 상태 유지)
- **꼭 확인할 것**: 숫자(비용·기간), 대상·조건, 문서에 없는 문장이 섞이지 않았는지. 신뢰도가 낮다고 표시되거나 '원문에서 찾지 못한 근거 문장'이 있으면 특히 주의하세요.
- 빈 답변('보완 필요') 초안은 직접 답변을 채운 뒤 '담당자 입력 필요'를 해제해야 승인할 수 있습니다.

### 4-12. 문서가 개정·삭제되었을 때 (재검토)
**개정본 올리기**: 문서 보관함에서 해당 문서의 **개정판 올리기**를 누르고 새 파일을 선택합니다. 이전 버전은 '이전 버전'으로 보관됩니다.

**그러면 자동으로**, 이전 버전 문서를 출처로 만든 **승인된 FAQ**에 **재검토 필요** 표시가 붙습니다.
- **FAQ의 승인 상태와 챗봇 답변은 그대로 유지**됩니다. 재검토 중에도 기존 답변은 계속 나갑니다(서비스가 끊기지 않음). 확인 후 필요하면 고치세요.
- 표시는 **대시보드**의 "재검토 필요 N건" 카드와 **FAQ 목록**의 배지에 나타납니다. FAQ 목록의 **재검토 필요만** 체크로 모아 볼 수 있습니다.

**재검토 방법** (FAQ 열기 → 상단 노란 안내 확인)
1. **새 문서로 초안 다시 만들기**를 누르면, 새 버전 문서에서 같은 질문의 답을 다시 만들어 **기존 답변(서비스 중)과 새 초안을 나란히** 보여줍니다. 이 단계에서는 아무것도 바뀌지 않습니다.
2. 새 초안이 맞으면 **새 초안 내용을 아래 답변 입력란에 채우기** → 확인 후 **저장** 또는 **수정 후 승인**. (재검토 완료 체크가 기본으로 켜져 있어 저장하면 표시가 사라지고, 출처가 새 문서로 옮겨집니다.)
3. 답변이 바뀔 필요가 없으면 **변경 없음 — 재검토 완료**를 누릅니다.

**문서를 삭제한 경우**: 출처 문서가 삭제되면 그 문서를 출처로 한 승인 FAQ에 사유 "삭제"로 같은 재검토 표시가 붙습니다(원문은 더 볼 수 없습니다). 답변은 계속 서비스되므로, 다른 자료로 답변이 여전히 맞는지 확인한 뒤 재검토를 완료하세요.

### 4-13. 문서 한 건에서 FAQ 초안 여러 건 만들기 (새 인증 도입 시)

미답변 질문이 없어도, 문서를 올려 두었다면 그 문서에서 FAQ 초안을 한 번에 여러 건 만들 수 있습니다. 새 인증을 들여오면서 관련 FAQ가 한꺼번에 필요할 때 쓰세요. 4-10의 '미답변 질문 → 초안 만들기'와 함께 쓸 수 있고, 서로 대체하지 않습니다.

1. **문서 보관함**에서 문서 상태가 **추출 완료**인지 확인합니다. 분류가 '기타 (초안 제외)'이거나 이전 버전(보관됨)인 문서는 실행되지 않습니다(사유가 표시됩니다).
2. 문서 행의 **FAQ 초안 만들기**를 누릅니다. 여러 문서는 앞의 체크박스로 고른 뒤 맨 위의 **선택한 문서 FAQ 초안 만들기**를 누릅니다. **청크 n/m** 으로 진행 상황이 보입니다. 이 화면을 닫으면 작업이 멈추며, 같은 문서의 **이어서 진행**으로 이어갈 수 있습니다.
3. 끝나면 **초안 N건 생성 · 탈락 M건**이 표시됩니다. 만들어진 초안은 항상 '초안' 상태이고 출처 문서·쪽이 기록됩니다. 승인은 4-11처럼 사람이 합니다.
4. **탈락 목록 보기**에서 걸러진 항목과 사유를 볼 수 있습니다. 필요한 내용이면 FAQ 등록 화면에서 직접 작성하세요.

**상한과 진행**: 한 번에 청크 5개씩 처리하고(질문·답변 문서는 10쌍씩) 진행 상태가 저장되어, 화면을 닫아 중단돼도 **이어서 진행**할 수 있습니다. 문서 한 건에서 만드는 후보는 **최대 50건**이며, 도달하면 "상한 도달, 분할 업로드 권장" 안내와 함께 중단합니다(넘친 후보는 탈락 목록에 남습니다). 청크 하나에서는 최대 3건입니다.

**자동으로 걸러지는 것**: 근거 문장이 원문에 없는 항목 · 답변의 숫자가 원문과 다른 항목 · 컨설팅성 내용 · IGSC 소관이 아닌 타 기관·법정 제도 안내 · 기존 FAQ(승인·초안 모두)와 같은 질문. 원문에 비용·기간 수치가 없는 비용·기간 질문은 빈 답변의 '보완 필요' 초안으로 남습니다.

**승인 완료 문서**: 문서에서 만든 FAQ가 모두 승인되면(미검수·보류 없음) 문서 행의 [FAQ 초안 만들기] 버튼은 "승인 완료" 표시로 바뀝니다. 내용을 바꿀 때는 **개정판 올리기**(재검토 표시가 붙음) 또는 FAQ 수정을 쓰세요. 이어서 해야 할 일이 남은 경우(작업 중단·상한 도달·처리 실패 항목)나 FAQ를 초안으로 되돌린 경우에는 버튼이 다시 보입니다.

**다시 만들기**: 이미 초안을 만든 문서는 **FAQ 초안 다시 만들기**로 표시됩니다. 이전에 이 기능이 만든 초안은 새 초안으로 교체되지만, **수정해 둔 초안, 미답변 질문에서 만든 초안, 승인된 FAQ는 그대로 유지**됩니다.

### 4-14. 문서에서 만든 초안을 한 화면에서 검수하기

문서 보관함의 문서 행에 **생성 n · 승인 n · 미검수 n**이 표시되고, 미검수가 있으면 **검수하기** 버튼이 나옵니다. 누르면 그 문서를 출처로 하는 초안을 한 화면에서 훑으며 처리할 수 있습니다(미답변 질문에서 만든 초안 포함).

- **카드**: 질문·답변을 그 자리에서 고칠 수 있고, 카테고리·'담당자 입력 필요' 표시·출처 쪽이 보입니다. **원문 보기**를 펼치면 근거 문장이 노란색으로 강조됩니다.
- **인증 종류·카테고리**: 카드에서 건별로 바꿀 수 있습니다(인증 종류는 문서의 값을 이어받고, 카테고리는 AI 판정값입니다). 바꾸면 그 값으로 저장됩니다.
- **승인**: 고친 내용이 저장되면서 승인되고, **즉시 챗봇이 사용**합니다. 답변이 비어 있으면 승인할 수 없습니다. '담당자 입력 필요' 항목은 답변을 직접 채워 승인하면 표시가 해제됩니다.
- **보류**: 초안으로 남기고 목록에서 흐리게 보입니다(미검수 건수에서 제외). **삭제**는 초안만 지워지며 승인된 FAQ는 지워지지 않습니다.
- **승인 기록**: 승인하면 승인한 관리자의 이메일과 시각이 항목마다 남고(일괄 승인도 건별로), FAQ 목록의 **승인자** 열과 FAQ 상세에서 확인할 수 있습니다. 관리자 3명 모두 생성·검수·승인할 수 있습니다(역할 분리 없음).
- **일괄 승인 / 전체 승인**: 하단 바에서 선택한 항목(또는 승인 가능한 전체)을 승인합니다. 누르면 "내용을 확인하셨나요?" 확인 창이 한 번 뜹니다. 보류·답변이 빈 항목·입력 필요 항목은 전체 승인에서 제외됩니다.
- **탈락 탭**: 자동으로 걸러진 항목과 사유·원문을 보여주고, **직접 작성**을 누르면 질문·원문이 채워진 FAQ 등록 화면으로 이동합니다.
- **키보드**: ↑↓ 이동, A 승인, S 보류, D 삭제(입력창 밖에서만 동작).

### 4-15. 인증 종류 추가·관리 (새 인증 도입 시)

새 인증 체계가 생기면 개발자를 부르지 않고 **관리자 → 인증 종류** 화면에서 직접 추가합니다.

- **추가**: 코드(영문 소문자·숫자·하이픈, 예: `pet-related-product`), 한글 이름, 영문 이름(선택), 분류(식품·화장품·지속가능성·검증·기타), 정렬을 입력하고 **추가**를 누릅니다. 문서 업로드와 FAQ 등록의 인증 종류 선택지에 **바로** 나타납니다. 코드는 만든 뒤 바꿀 수 없으니 신중히 정하세요.
- **수정·비활성화**: 이름·분류·정렬을 고치거나 **활성** 체크를 풀고 **저장**합니다. 비활성화해도 그 인증의 기존 FAQ·이력·문서는 그대로 유지되고, 신규 등록 선택지에서만 빠집니다. 표의 **사용 중** 칸에서 이 인증을 쓰는 FAQ·문서·이력 건수를 볼 수 있습니다.
- **정렬**: 0은 가나다순(기본), 1 이상이면 숫자가 작은 순서로 앞에 옵니다.
- 챗봇과 다른 서버에는 최대 10분 안에 반영됩니다(같은 서버는 즉시).

### 4-16. 비슷한 FAQ 경고와 중복 방지

- **FAQ 직접 등록·수정**: 질문과 인증 종류를 입력하면 같은 인증 종류의 승인·초안 FAQ 중 의미가 같은 질문을 찾아 **"비슷한 FAQ가 있습니다"** 경고와 링크를 보여줍니다. 경고만 하고 저장은 그대로 할 수 있습니다.
- **문서에서 FAQ 초안 만들기(4-13)**: 같은 인증 종류에 같은 질문이 이미 있으면 탈락 처리하고, 탈락 사유에 **기존 FAQ 보기** 링크를 붙입니다. 같은 문서를 두 번 처리해도 같은 FAQ가 두 번 만들어지지 않습니다.
- 같은 질문이라도 **인증 종류가 다르면 중복이 아닙니다.** 같은 비건 코드 안에서도 질문에 드러난 대분류(식품 비건·화장품 비건)가 다르면 별개로 봅니다.

### 4-17. 문서 올리기 규칙 (중복·형식·추출 품질)

- **중복 파일**: 이미 올라간 파일과 **내용이 같은 파일**은 올릴 수 없습니다(파일 이름이 달라도 내용이 같으면 막히고 기존 문서를 알려 줍니다). 내용은 다르고 **이름만 같은 파일**이면 선택 창이 뜹니다: **개정판으로 올리기**(기본) / 별도 문서로 올리기 / 취소. 개정판으로 올리면 이전 버전은 '이전 버전'으로 보관되고 그 문서로 만든 승인된 FAQ에 재검토 표시가 붙습니다.
- **문서 형식**: 업로드할 때 **설명 자료**(기본) 또는 **질문·답변이 정리된 자료**를 고릅니다. 질문·답변 자료(Q&A 문서, 2열 표, Q:/A: 형식)는 AI가 질문을 새로 만들지 않고 **원문의 질문·답변을 그대로** 가져옵니다. 올린 뒤 문서 행의 **형식 확인**을 누르면 처음 3건이 미리보기로 나오고, "형식이 맞습니까?"를 확인해야 FAQ 초안을 만들 수 있습니다. 맞지 않으면 설명 자료로 바꿀 수 있습니다.
- **스캔 문서**: PDF에서 페이지당 평균 글자가 50자 미만이면 스캔 문서로 보고 '추출 실패'로 처리합니다("텍스트가 있는 원본 파일을 올려 주세요"). 원본(DOCX, PPTX 등)을 올려 주세요.

## 6. FAQ 잘 쓰는 법

### 기본 원칙
1. **FAQ 하나에 질문 하나.** 여러 질문을 한 FAQ에 섞지 마세요.
2. **질문에 인증 종류를 넣으세요.** 특히 이름이 같은 다른 인증(식품 비건 / 화장품 비건)은 대분류까지 적습니다.
3. **답변은 확정된 사실만.** 비용·기간은 담당자가 확정한 값만, 기준일이나 변동 요인(제품 수, 시설 수 등)이 있으면 함께 적습니다. 모르면 답변을 비우고 '담당자 입력 필요'로 두세요.
4. **다른 표현을 충분히.** 챗봇이 FAQ를 찾을 때 '질문'과 '다른 표현'을 봅니다. 대화 로그의 실제 고객 표현("비건인증 얼마", "가격이 어떻게 돼요")을 그대로 추가하세요.
5. **출처 URL을 넣으세요.** 고객이 원문을 확인할 수 있고 신뢰도가 올라갑니다.

### 예시

| | 좋은 FAQ | 고치면 좋은 FAQ |
|---|---|---|
| 질문 | 식품 비건(Vegan) 인증의 원칙은 무엇인가요? | 비건 관련 (범위가 넓음) |
| 답변 | 동물 및 동물 유래 성분 금지, 동물 실험 금지, 교차 오염 금지의 세 가지 원칙입니다. | 보통 3~4주 걸립니다 (근거 없는 추정) |
| 다른 표현 | 비건 인증 기준, 비건 심사 원칙 | (없음) |

### 넣지 말아야 하는 것
- **컨설팅성 내용** (통과하는 방법, 기준 맞추는 법, 준비·개선 조언). 챗봇은 이런 질문에 FAQ를 보지 않고 거절하지만, 이런 FAQ가 승인되어 있으면 다른 질문에서 노출될 위험이 있습니다.
- **추정·일반 상식** ("보통", "대략", "일반적으로")
- **개인정보**, 다른 기관의 정보

### 승인 전 체크리스트
- [ ] 질문이 하나의 주제이고 인증 종류가 드러난다
- [ ] 답변의 모든 내용이 공식 자료·담당자 확정값과 일치한다
- [ ] 비용·기간이면 기준일과 변동 요인을 적었다
- [ ] 컨설팅성 표현이 없다
- [ ] 출처 URL과 다른 표현이 있다

> **규모 참고**: 현재 방식은 승인 FAQ가 **약 200건 이하**일 때 정확하고 빠릅니다. 200건을 넘길 것 같으면 개발사에 검색 방식 교체를 문의하세요.

## 7. 인증 이력(cert_history) 입력

제품 인증 가능 여부 문의(예: "고체 탈취제도 반려동물 인증 되나요?")에서 챗봇은 **가능 여부를 확답하지 않고**, 유사한 제품군의 **공개 동의된 인증 이력**을 참고로 안내합니다. 이력이 없으면 담당자 검토 안내로 처리됩니다.

> 현재 관리자 화면에는 이력 입력 화면이 없습니다. **Supabase 대시보드 → Table Editor → `cert_history`** 에서 직접 입력합니다. (입력 화면이 필요하면 개발사에 요청하세요.)

| 컬럼 | 입력 방법 |
|---|---|
| `cert_type` | 인증 **코드값** — 부록 B의 표에서 선택 (예: 반려동물 관련 제품 → `pet-related-product`). 한글 이름을 직접 적으면 그대로 표시됩니다. |
| `product_category` | 제품군을 고객이 알아볼 표현으로 (예: 반려동물 위생용품) — 챗봇이 이 문구로 유사 여부를 판단합니다 |
| `company_public` | **공개에 동의한 경우에만 `true`**. `false`인 이력은 챗봇이 전혀 사용하지 않습니다 |
| `company_name` | 공개 동의(`true`)된 경우에만 안내에 표시됩니다 |
| `year` | 인증 연도 |

## 8. 문제 해결

| 증상 | 확인·조치 |
|---|---|
| 저장했는데 챗봇이 예전 답을 함 | FAQ 상태가 `승인`인지, '담당자 입력 필요'가 꺼져 있는지 확인. 고객 질문이 FAQ와 많이 다르면 **다른 표현**에 그 말투를 추가 |
| 승인이 안 됨 | 답변이 비었거나 '담당자 입력 필요'가 켜져 있음 (사유가 화면에 표시됨) |
| 챗봇이 엉뚱한 FAQ로 답함 | 대화 로그에서 근거 FAQ 확인 → 해당 FAQ의 질문을 구체적으로 수정(인증 종류 명시), 또는 초안으로 내리기 |
| 답해야 할 질문에 계속 "담당자 확인" | 미답변 질문에서 FAQ로 등록. 같은 질문이 반복되면 Top 10에 올라옵니다 |
| 문서를 올렸는데 초안이 안 만들어짐 | 문서 상태가 **추출 완료**인지 확인. 스캔 PDF·이미지 문서는 추출 실패 → 텍스트 PDF/DOCX로 다시 올리기 |
| 초안의 출처가 인증과 무관한 문서(내부 매뉴얼 등)임 | 그 문서의 분류가 '기타'가 아닌지 확인. 인증 근거가 아닌 문서는 삭제하거나 분류를 '기타'로 올려 초안 재료에서 빼세요 |
| 초안이 빈 답변('보완 필요')으로 만들어짐 | 문서에 그 질문의 근거 문장이 없거나 검증에서 탈락한 것입니다. 목록의 사유를 확인하고 직접 작성 |
| '컨설팅 요청이라 초안을 만들지 않았습니다' | 정상 동작입니다(ISO 17065 공평성). 담당자가 직접 판단해 응대 |
| 문서를 개정했는데 FAQ에 표시가 안 붙음 | 그 FAQ가 **승인 상태**이고 그 문서에서 만든 FAQ인지 확인. 직접 등록한 FAQ나 초안은 대상이 아닙니다 |
| HWP 파일이 안 올라감 | 지원하지 않는 형식입니다. 한글에서 PDF로 저장해 올리세요 |
| 비용·기간이 안 나옴 | 해당 FAQ가 '보완 필요' 상태(답변 비어 있음). 확정값을 입력하고 승인 |
| 인증 종류 목록에 없는 인증 | 개발사에 추가 요청 (9장) |
| 로그인 링크가 안 열림 | 링크를 **요청한 브라우저와 같은 브라우저**에서 여는지, 오래된 링크가 아닌지 확인 후 다시 요청. 스팸함도 확인 |
| 로그인 메일이 안 옴 | 등록되지 않은 이메일은 발송되지 않음. 관리자 등록 여부 확인 |
| 챗봇 버튼이 사이트에 안 보임 | 삽입 코드 확인 — `docs/widget-install.md` |
| 챗봇이 "일시적인 문제로 답변을 드리지 못했습니다" | 일시 오류입니다. 반복되면 개발사에 문의 (대화 로그에는 '담당자 이관'으로 남고 미답변 목록에도 올라갑니다) |

## 부록 A. 용어

| 용어 | 뜻 |
|---|---|
| FAQ | 질문과 답변 한 쌍. 챗봇이 답하는 유일한 근거 |
| 승인 / 초안 | 승인된 FAQ만 챗봇이 사용. 초안은 작업 중인 상태 |
| 보완 필요 | 답변이 아직 없는 FAQ (`담당자 입력 필요` 표시) |
| 다른 표현 | 같은 질문의 다른 말투. 챗봇이 FAQ를 찾는 데 쓰임 |
| 담당자 이관 | 챗봇이 답하지 않고 사람에게 넘기는 처리 |
| 미답변 질문 | 이관된 질문이 모이는 목록 — FAQ 보강의 출발점 |
| 처리 결과(route) | 대화 하나가 어떻게 처리됐는지(2장 표) |
