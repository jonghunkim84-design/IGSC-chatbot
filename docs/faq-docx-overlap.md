## 2. 충돌 (1건) — 고객 결정 필요

**Q53. 인증 취득 후 인증 마크(로고)를 사용할 수 있나요?**

| | 내용 |
|---|---|
| 고객 문서 | 인증 취득 후 **바로** 사용할 수 있고, 유효기간 전까지 사용 가능 |
| 기존 FAQ (승인됨) "IGSC 인증마크(로고) 사용 허가는 언제 발생하나요?" | **서면 신청 승인과 수수료 지불**이 완료되고, **인쇄 전 IGSC의 승인**을 받은 후에 사용 허가가 발생. 포장의 모든 로고 사용 증명자료는 상거래 사용 전 IGSC 승인 필요 |

- 두 문장이 모순일 수도, 맥락이 다른 것일 수도 있다(예: 마크 일반 사용 vs 포장 인쇄물).
- **지금 챗봇은 기존(승인) FAQ대로 답한다.** 문서 쪽을 신규 승인하면 같은 질문에 서로 다른 답이 나갈 수 있다.
- 결정 필요: "취득 즉시 사용 가능"이 맞는지, 포장·인쇄물에는 별도 승인이 필요한 것이 맞는지. 확정되면 한 항목으로 통합 권장.

## 5. 승인 전에 확인할 점 (이 문서 내용이 챗봇 원칙과 부딪힐 수 있는 부분)

1. **비용·기간 규칙** — 챗봇은 확정값만 안내해야 한다. 다음 문서 답변은 비용·기간 수치를 담고 있어 **고객이 확정값으로 승인**해야 FAQ로 쓸 수 있다.
   - Q47 급행: "서류 심사는 급행 가능, **비용 1.5배**"
   - Q46 최단 기간 "1달 이내", Q30 현장심사 "보통 1일, ISO는 직원수에 따라"
   - Q45 불승인 시 "**비용은 환불되지 않음**, 재시험 비용 별도" (환불 정책이라 표현 확인 필요)
2. **문서 안의 모호한 부분**
   - Q26 "모든 인증은 원격 심사 가능. 대신 코로나, 방문이 어려운 특수한 경우"는 앞뒤가 어긋난다. 어떤 경우에 가능한지 명확히 해야 한다.
   - Q14 해외 공장은 "방문 혹은 원격으로 현장심사"라고 해서 Q26과 함께 정리가 필요하다.
   - Q13 "인증 제품이 무엇인지 알려주시면 확인 후 답변을 드리겠습니다"는 담당자 안내 문구라 FAQ 답변이 아니라 이관 처리가 맞다.
3. **조회 사이트 주소(Q50)**: 문서에 `igsc.kr/zh/certification/certification_status`(중국어 경로)로 적혀 있다. 한국어 주소 `igsc.kr/certification/certification_status`로 바꿔야 한다.
4. **컨설팅 경계**: Q15 "비건은 동물성 성분이 있으면 신청 불가" 같은 기준 설명은 가능하지만, "어떻게 하면 통과하나요" 식으로 확장되지 않게 주의.
5. **번호 누락**: 문서 질문 번호가 1~69인데 47건만 있다(Q8~11, 18, 21~23, 27~29, 33~35, 41~44, 48, 59, 64, 68 등 22개 빠짐). 고객이 의도적으로 뺀 것인지, 누락인지 확인이 필요하다.
