# IGSC 인증 문의 챗봇 — 고객 확인·결정 사항

정식 운영을 시작하려면 아래 항목을 **IGSC에서 확인·결정**해 주셔야 합니다. 시스템 구축과 기능 개발은 끝났고, 남은 일은 대부분 **내용(FAQ)의 확정**과 **운영 기준**입니다.

> 기준일 2026-10-04 · 시스템 https://igsc-chatbot.vercel.app · 각 표의 **결정 내용 / 담당자 / 기한** 칸은 교육·협의 때 함께 채웁니다.

## 0. 현재 상태 요약

| 항목 | 현재 |
|---|---|
| 챗봇·관리자 화면 | 운영 환경에 배포 완료 (홈페이지 삽입 전) |
| 승인된 FAQ | **0건** — 개발 중 임시로 승인했던 항목은 모두 초안으로 되돌렸습니다. 지금은 챗봇이 어떤 질문에도 답을 하지 못합니다. |
| FAQ 초안 | 고객 FAQ 문서·공개 페이지·필요서류·절차·소개자료·**비용·기간 안내**에서 만든 초안. 답변이 채워진 것은 바로 검수할 수 있고, 답변이 비어 있는 '보완 필요' 항목은 고객이 내용을 정해 주셔야 합니다. 비용·기간 FAQ는 새로 반영해 **재승인 대기** 상태입니다. |
| 인증 이력 | 220건 적재(`igsc.kr` 인증 현황 기준, 업체명은 노출하지 않음). 개발 중에는 전부 공개로 두었고, **인계 시 비공개로 전환**합니다. |
| 테스트 데이터 | 대화 기록·미답변 질문·테스트 FAQ·테스트 문서를 모두 정리했습니다. |
| 보호 장치 | 요청 제한(과다 사용 방지), 보안 헤더, 운영 모니터링(DB·AI 점검, 이메일 알림), 승인자 기록 적용 완료 |

## 1. 운영 시작 전에 꼭 정해야 할 것

### 1-1. FAQ 검수·승인

| # | 항목 | 현재 상황 | 필요한 결정·자료 | 결정 내용 / 담당자 / 기한 |
|---|---|---|---|---|
| 1 | **검수·승인 담당자와 기준** | 챗봇은 **승인된 FAQ만** 근거로 답합니다. 승인은 항상 사람이 합니다. 초안 436건이 검수 대기입니다. | 누가 승인하는지(관리자 최대 3명), 승인 기준, **우선 검수 범위**(예: 문의가 많은 인증·공통 FAQ부터) | |
| 2 | **비용·기간 확정값** | 고객이 보내 주신 비용·소요기간(2026-10-07, 2차 확인 포함)을 FAQ 초안으로 반영했습니다. **금액은 부가세 별도**이고, "기본" 인증(비건 해외용, Gluten Free, GMO Free, Sugar Free, Lactose Free/Dairy Free, Salt Free, Fat Free, Caffeine Free, Calorie Free, Ketogenic friendly, Plastic free)은 200만원·현장심사 이후 4~6주, ISO는 직원 수에 따라 별도 문의입니다. **아직 확인이 필요한 것**: ① Microplastic-free 금액(첫 안내 최종 250만원, 2차 확인 300만원 — 현재 300만원 반영) ② Caffeine Free 인증 종류 등록·금액 표기 ③ ISO 9001 외 ISO별 금액표(예시 3구간만 받음) ④ 비건 해외용 소요기간(기본 인증 기준 4~6주 적용) | 위 ①~④ 확인, 비용·기간 FAQ 검수·승인 | |
| 3 | **인증 절차 확정** | 절차가 문서마다 다릅니다: `Certification Audit Process_2025`(10단계) / `인증절차 안내_260511`(8단계) / FAQ 문서 Q16. 지금은 8단계 문서와 FAQ 문서 기준 초안만 등록했습니다. | **현행 절차 확정** (10단계 문서로 만든 FAQ는 등록하지 않았습니다) | |
| 4 | **인증 마크(로고) 사용 시점** | FAQ 문서 Q53은 "취득 후 바로 사용", 기존 FAQ는 "서면 승인·수수료·인쇄 전 승인"으로 **서로 충돌**합니다. | 어느 쪽이 맞는지, 맞는 내용으로 FAQ를 하나로 정리 | |
| 5 | **FAQ 문서의 '보완 필요' 항목** | Q13, Q14, Q26, Q30, Q45, Q46, Q47, Q50 — 수치가 없거나 표현이 모호하거나 주소 오류가 있습니다. Q13은 담당자 안내 문구라 FAQ가 아니라 이관 대상입니다. | 각 항목의 확정 문구 | |
| 6 | **필요서류 PDF 주석** | "제품인증" 서류 PDF의 마지막 주석이 `Upcycled Materia…`에서 끊겨 있습니다. | 전체 문구 | |

### 1-2. 자료 수령

| # | 자료 | 사유 | 결정 내용 / 담당자 / 기한 |
|---|---|---|---|
| 7 | **원본 파일**: 반려동물인증·Monde Selection·KETO·MyMicrobiome·Flustix 소개자료, JAS 절차(PPTX 등) | 현재 파일은 글자가 깨지거나 이미지뿐이라 FAQ 초안을 만들지 못했습니다. PPTX·DOCX 같은 **원본**이면 만들 수 있습니다. (HWP는 PDF로 변환해 주세요.) | |
| 8 | 인증별 **서류·절차·기간** 문서 중 아직 없는 것 | 예: EPD는 "무엇인가요" 위주라 절차 질문에 답하지 못합니다. 문서가 있으면 초안을 한 번에 만들 수 있습니다. | |

> **자료 원칙** — 문서는 FAQ 초안의 재료일 뿐, 고객에게 나가는 답변은 승인된 FAQ만 근거입니다. 문서에 근거가 없으면 답을 만들지 않고 '보완 필요'로 남깁니다. 외부 자료·내부 매뉴얼은 올리지 않습니다. 문서가 개정되면 관련 FAQ에 재검토 표시가 붙고(답변은 계속 서비스), 담당자가 확인합니다.

### 1-3. 인증 이력(유사 사례) 공개

| # | 항목 | 현재 상황 | 필요한 결정 | 결정 내용 / 담당자 / 기한 |
|---|---|---|---|---|
| 9 | **공개 동의 확인** | "우리 제품도 인증되나요?"에 챗봇이 **유사 제품의 인증 이력**을 참고로 안내합니다(업체명은 노출하지 않음). 공개 인증 현황 220건이 올라가 있으나, 업체별 **공개 동의 여부**는 확인되지 않았습니다. | 이력 안내를 해도 되는지, 대상 범위. **확인 전에는 비공개로 인계**합니다. | |

## 4. 이미 적용된 보호 장치 (확인용)

| 장치 | 내용 |
|---|---|
| 승인된 FAQ만 답변 | 근거가 없으면 답을 만들지 않고 담당자에게 연결 |
| 컨설팅 거절 | 통과 방법·기준 맞추는 법은 답하지 않음 (공평성) |
| 비용·기간 | 등록된 확정값만 안내, 항상 "참고용" 문구 |
| 요청 제한 | 한 사용자가 분당 15회·시간당 120회, 전체 하루 3,000건 초과 시 "잠시 후 다시 시도" 안내 / 로그인 메일 요청도 제한 |
| 승인 기록 | 승인한 관리자 이메일과 시각이 항목마다 남음 |
| 운영 모니터링 | AI·DB 연결과 오류율 점검, 문제 시 관리자 이메일 알림 (운영 상태 화면) |
| 보안 헤더 | 다른 사이트의 프레임 삽입 제한(챗봇 화면 제외), 기타 표준 보안 헤더 |
| 자동 점검 | 대표 질문 42건 회귀 점검(안전 규칙 포함)으로 변경 시 품질 확인 |

## 5. 제안 일정 (예시)

| 단계 | 내용 | 담당 |
|---|---|---|
| ① 사용자 교육 | 관리자 화면 사용법 교육·실습 | 개발사 / IGSC 운영 담당 |
| ② 자료·결정 | 이 문서의 1~3장 항목 확정, 비용·기간 값, 원본 파일 | **IGSC** |
| ③ 초안 생성·검수 | 새 자료로 FAQ 초안 생성 → 담당자 검수·승인 (승인은 항상 사람) | IGSC 검수 / 개발사 지원 |
| ④ 공개 준비 | 서비스 명의 이전·키 재발급, 도메인·알림 메일 설정, 위젯 삽입, 최종 점검 | 개발사 / 삽입 업체 |
| ⑤ 공개·운영 | 일일 미답변 확인 루틴, 주간 지표 점검(답변 성공률, 많이 묻는 질문) | IGSC 운영 담당 |

**권장 우선순위**: 먼저 ①검수 담당자·기준, ②비용·기간 값, ③절차 확정 — 이 셋이 정해져야 가장 많이 묻는 질문(비용·기간·절차)에 챗봇이 답할 수 있습니다.
