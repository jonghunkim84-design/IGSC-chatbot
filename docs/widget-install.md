# IGSC 인증 문의 챗봇 삽입 가이드

## 1. 삽입 코드

아래 **한 줄**을 사이트 **모든 페이지의 `</body>` 바로 위**에 넣습니다. (공통 푸터/레이아웃 파일에 한 번만 넣으면 됩니다.)

```html
<script src="https://igsc-chatbot.vercel.app/widget.js" async></script>
```

- 위 주소가 현재 배포된 챗봇 주소입니다. 정식 도메인으로 바뀌면 IGSC에서 새 주소를 전달드립니다.
- 이 한 줄이 전부입니다. CSS/JS 파일을 따로 추가하지 않습니다.
- 같은 페이지에 두 번 넣어도 한 번만 동작합니다.

## 2. 동작

| 화면 | 동작 |
|---|---|
| PC | 우측 하단에 동그란 버튼 표시 → 클릭하면 380×640 크기의 대화창이 열림 |
| 모바일 (폭 480px 이하) | 버튼 클릭 시 전체 화면으로 열림, 우측 상단 ✕ 로 닫기 |
| 공통 | 버튼 재클릭 / ✕ / ESC 키로 닫기 |

- 사이트의 CSS와 서로 영향을 주지 않도록 격리되어 있습니다. 사이트 CSS를 수정할 필요가 없습니다.
- 대화창은 버튼을 처음 누를 때 로드되므로 페이지 로딩 속도에 영향이 거의 없습니다.

### 유입 채널 표시 (선택)
위젯은 자동으로 이 방문을 **홈페이지** 채널로 기록합니다. 다른 사이트에 넣을 때 채널 이름을 바꾸려면 삽입 코드에 `data-src` 를 붙입니다(채널 코드는 `docs/channels.md`).
```html
<script src="https://{챗봇 도메인}/widget.js" data-src="homepage" async></script>
```

## 3. 설치 후 확인 (체크리스트)

- [ ] 우측 하단에 초록색 원형 버튼이 보인다
- [ ] 버튼을 누르면 "IGSC 인증 문의를 안내해 드립니다." 화면이 열린다
- [ ] 추천 질문 4개(인증 비용 / 소요 기간 / 인증 절차 / 인증 종류 안내)가 보인다
- [ ] 스마트폰에서 전체 화면으로 열리고 ✕ 로 닫힌다
- [ ] 다른 요소(사이트 메뉴, 하단 고정 배너 등)가 챗봇 버튼을 가리지 않는다

## 4. 사이트에 보안 정책(CSP)이 설정된 경우

사이트에 `Content-Security-Policy` 헤더가 있다면 아래 두 가지를 허용해야 합니다.

```
script-src  https://igsc-chatbot.vercel.app
frame-src   https://igsc-chatbot.vercel.app
```

## 5. 문의 / 문제 해결

| 증상 | 확인 |
|---|---|
| 버튼이 안 보임 | 삽입 코드의 도메인 오타 확인 → 브라우저 개발자도구(F12) Console/Network 에서 `widget.js` 가 200 으로 로드되는지 확인 |
| 버튼은 보이는데 대화창이 비어 있음 | 개발자도구 Console 에서 `frame-ancestors` 또는 `Refused to frame` 메시지 확인 → IGSC 담당자에게 사이트 도메인 전달 |
| 다른 요소에 가려짐 | 챗봇 버튼의 z-index 는 최댓값에 가깝게 설정되어 있음. 가려진다면 해당 요소의 z-index 를 확인 |

## 6. 제거

삽입한 `<script>` 한 줄을 삭제하면 됩니다.

### IGSC 내부 참고 (외주 업체에는 전달하지 않아도 됩니다)

- 현재 주소는 Vercel 기본 도메인(`igsc-chatbot.vercel.app`)입니다. 정식 도메인을 연결하면 이 문서의 주소를 모두 바꿔 다시 전달하세요.
- 대화창(`/chat`)을 열 수 있는 사이트를 제한하려면 배포 환경변수 `CHAT_FRAME_ANCESTORS` 에 허용 도메인을 공백으로 구분해 지정합니다. (예: `https://www.customer.co.kr https://*.customer.co.kr`) 지정하지 않으면 모든 사이트에서 열립니다.
- 로컬 테스트: `npm run dev` 후 `http://localhost:3000/widget-test.html` (일부러 사이트 CSS 충돌 상황을 만든 테스트 페이지). 이 페이지는 운영 배포 전에 `public/widget-test.html` 을 삭제하세요.
