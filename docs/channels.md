# 유입 채널 관리

챗봇 링크를 여러 곳(네이버 블로그, 링크드인, 인스타그램, 직원 이메일 서명, 홈페이지)에 걸어 두고, **어느 채널에서 질문과 문의가 얼마나 들어왔는지**를 관리자 화면에서 봅니다.

## 어떻게 동작하나
- 채널마다 **표시가 붙은 링크**를 겁니다: `{챗봇 주소}/chat?src={채널 코드}` (선택: `&c={캠페인 이름}`)
- 고객이 그 링크로 들어와 질문하면, 질문 기록(대화 로그)에 채널이 함께 남습니다. 고객 정보는 저장하지 않습니다(채널 이름만).
- 관리자 → **유입 채널** 에서 기간별로 채널당 대화 수·질문 수·비중·답변 성공률을 확인하고, 링크를 만들어 복사합니다.

| 채널 | 코드 | 링크 예 |
|---|---|---|
| 홈페이지 | `homepage` | 홈페이지의 챗봇 버튼(위젯)은 자동으로 기록됩니다. 홈페이지 안에 직접 링크를 걸 때는 `/chat?src=homepage` |
| 네이버 블로그 | `naver-blog` | `/chat?src=naver-blog` |
| 링크드인 | `linkedin` | `/chat?src=linkedin` |
| 인스타그램 | `instagram` | `/chat?src=instagram` (프로필 링크, 스토리 링크는 `&c=story` 처럼 구분) |
| 직원 이메일 서명 | `email-signature` | `/chat?src=email-signature` (직원별로 보려면 `&c=kim` 처럼 이름을 붙임) |

링크는 관리자 화면(유입 채널)에서 **현재 챗봇 주소 기준으로 자동 완성**되므로, 도메인이 바뀌어도 거기서 다시 복사하면 됩니다.

## 캠페인 이름(`c`)
같은 채널 안에서 게시물·담당자·시기를 나누어 보고 싶을 때 씁니다. 소문자 영문·숫자·`-`·`_` 만, 40자 이내(예: `story-1010`, `kim`, `blog-2610`). 관리자 화면에서는 채널 아래에 캠페인별 질문 수가 나옵니다. **코드를 고칠 필요가 없습니다.**

## 집계 기준과 한계
- **질문 수** = 챗봇에 입력된 메시지 수, **대화 수** = 질문을 한 방문(브라우저 탭) 수. 챗봇을 열기만 하고 질문하지 않은 방문은 집계되지 않습니다. (방문 수·전환율이 필요하면 별도 추적을 추가해야 합니다.)
- 링크에 `src` 가 없으면 이전 페이지 주소(Referer)로 블로그·링크드인·인스타그램을 짐작합니다. 짐작할 수 없으면 "직접 입력·알 수 없음"입니다.
- 링크 단축 서비스가 뒤의 `?src=…` 를 지우면 "직접 입력·알 수 없음"으로 들어갑니다 → **완성된 링크를 단축**하세요.
- 날짜는 한국 시간 기준입니다. 이 기능을 켜기 전(마이그레이션 0012 적용 전)의 대화는 채널을 알 수 없습니다.
- 채널을 새로 추가하려면 `lib/channels.ts` 의 `CHANNELS` 에 한 줄을 추가합니다(Claude Code에게 요청). 등록되지 않은 `src` 값은 "기타"로 모이고 원래 값이 캠페인 칸에 남습니다.

## 개인정보
저장하는 것은 채널 코드와 캠페인 이름뿐입니다. IP·이메일·브라우저 정보는 채널 집계에 쓰지 않습니다.
